# 発信方針

## フェーズ1：集客期（現在）

**目的：** 「AI・業務自動化を頼める人」として認知され、ココナラで最初の受注を得る。

- 記事の比率：無料の集客記事 8〜9割 / 有料記事 1〜2割（作るなら低価格の単発記事のみ）
- 主な読者：店舗オーナー・個人事業主・小規模事業の担当者（`persona.md` の A）
- 主力テーマ：Gmail・Googleフォーム・カレンダー・スプレッドシートの自動化（ココナラの3サービスと同じ範囲）。LINE Bot などそれ以外の作品は「Google以外も作れる」実力の証明として月1本程度
- 記事の型：開発記（`dev-story`）、導入事例・解説（`case-study`）、店舗の悩み起点の解説
- 導線：記事末尾でココナラの該当サービスへ。該当がなければポートフォリオへ
- 書かないもの：学習者向けの細かいコード解説（フェーズ2で有料化する素材として残す）

### 指標（月1回見直す）

- 記事からココナラへのクリック数（note の記事ごとのアクセス解析で見る）
- ココナラの閲覧数・お気に入り数・問い合わせ数
- note のフォロワー数

## フェーズ2：販売期

**切り替え条件（どれか1つ）：** ココナラで受注実績 3件 / note フォロワー 100人 / 有料記事が自然に売れた

- 受注で得た実績（伏せ字にしたもの）を記事化 → 「実績のある人のノウハウ」として有料記事・マガジンを作る
- 読者に `persona.md` の B（副業・学習者）を加える
- 記事の型 `how-to`・`paid-article` を本格的に使う

## なぜ集客を先にするか

- 実績ゼロの段階では、ノウハウ記事に「この人から買う理由」がない
- 集客記事は受注につながり、受注は次の記事のネタになる。順番を逆にすると素材が増えない
- 有料記事の素材（コード解説・営業ノウハウ）は消えないので、フェーズ2まで貯めておける
